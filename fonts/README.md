`install.sh` downloads four free display fonts here (SIL Open Font License, from Google Fonts):
Anton (`poster`, `condensed`), Archivo Black (`wide`), Space Mono Bold (`mono`) and Amatic SC Bold (`hand`).
Drop any other .ttf here too, e.g. Montserrat Black (`heavy`). Aliases: heavy, condensed, bold, regular, poster, wide, mono, hand.
